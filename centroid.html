How It Works

Firstly, this program is designed in conjunction with my Spring 2026 research at the University of Central Florida working on mapping formations in martian craters that support evidence of liquid water, whether its pits, gullies, pāhoehoe-like features, or others. Specifically, this program is designed to find the average and median distances between pit formations and their neighbors.


The program starts by opening a dialog box for the user to select a .csv file containing the raw data of the polygons from the crater pit mapping. From there the centroid latitudes, longitudes, and pit IDs are extracted and stored in numpy arrays. From there two functions are defined, one to calculate the Haversine distance between two points on Mars (fast_distance()), and another to calculate the direction (direction()). These are needed to find the distance between two centroids using latitude and longitude, and to find the direction between points so each pit can be classified into one of 36 directional bins (one per 10 degrees).

The next function (find_neighbors()) takes in the index of a pit to lookup, forms 36 direcitonal bins, and calculates the distance and direction to every other pit. If the distance is less than the current minimum in that direction, then the current pit is a closer neighbor and stored as the new minimum distance. This is repeated for every pit. The output of this function is an array of the minimum distance to a neighbor in each of the 36 directional bins.

Finally, to calculate the overall mean and median, each pit's neighboring distance array is calculated and the average/median of that list is stored. After each pit is interated through, the overall average and median are found using the lists of averages and medians for each pit. This is done so calculations are limited to only N number of pits and not N*36.

Haversine Distance Calcultion on Mars

 
MARS_RADIUS = 3389500  # meters (mean radius)

def fast_distance(lat1, lon1, lat2, lon2):
    lat1, lon1, lat2, lon2 = map(math.radians, (lat1, lon1, lat2, lon2))
    dlat = lat2 - lat1
    dlon = lon2 - lon1

    a = (math.sin(dlat / 2) ** 2 +
         math.cos(lat1) * math.cos(lat2) * math.sin(dlon / 2) ** 2)

    return 2 * MARS_RADIUS * math.asin(math.sqrt(a))

def direction(lat1, lon1, lat2, lon2):
    angle = math.degrees(math.atan2(lon2 - lon1, lat2 - lat1))
    return angle % 360

def find_neighbors(idx):
    lat0 = lats[idx]
    lon0 = lons[idx]

    # 36 directional bins (one per 10 degrees)
    min_dist = np.full(36, np.inf)

    for j in range(N):
        if j == idx:
            continue

        dist = fast_distance(lat0, lon0, lats[j], lons[j])
        dire = direction(lat0, lon0, lats[j], lons[j])

        bin_idx = int(dire // 10)

        if dist < min_dist[bin_idx]:
            min_dist[bin_idx] = dist

    return min_dist
